# 法定相続情報一覧図 作成ツール

亡くなった方とご家族（相続人）の情報を入力するだけで、法務局に提出する「法定相続情報一覧図」と「申出書」をまとめて作れる、一般の方向けの無料Webツールです。
インストールや会員登録は不要で、ブラウザで開いてすぐに使えます。

**▶ ツールを開く：https://directfuneral.github.io/souzoku-ichiranzu/**

## このツールでできること

- **法定相続情報一覧図の作成**
  だれが相続人なのかを家系図のような形でまとめた書類を、法務局の記載例に沿った形で作ります。印刷・PDF保存のほか、Excelファイルでも出力できます。
- **申出書の作成（Word出力）**
  一覧図と一緒に提出する「法定相続情報一覧図の保管及び交付の申出書」を、法務局の様式（Wordファイル）に書き込んだ形で出力します。一覧図で入力した内容は申出書にも自動で入るので、同じ内容を2回入力する必要はありません。
- **必要書類のチェックシート**
  質問に答えていくと、「だれの」「どのような」戸籍や住民票を集めればよいかの一覧と、簡単な相続関係図ができあがります。
- **提出先の法務局の自動判定**
  本籍地や最後の住所などから、管轄の法務局（支局・出張所）を自動で判定し、郵送用の住所も表示します。
- **入力内容の保存と読み込み**
  入力途中の内容をファイルやブラウザに保存して、あとから続きを作業できます。

## 使い方

1. 上のリンクからツールを開きます。
2. 右側の「添付資料」タブで質問に答え、集める戸籍や住民票を確認します（必要な方のみ）。
3. 集めた戸籍をもとに、相続人のパターン（子・親・兄弟姉妹）を選びます。
4. 亡くなった方、配偶者、ほかの相続人、作成者の情報を、戸籍や住民票のとおりに入力します。
5. 申出書の欄を入力します。
6. 右側の見本を確かめてから、一覧図を印刷（またはPDF・Excel出力）し、申出書をWordで出力します。

くわしい操作方法は、ツール画面の左上にある **「？ 使い方」** ボタンからご覧いただけます。

### 印刷するときの設定

一覧図を印刷・PDF保存するときは、印刷画面で次のように設定してください。

- 用紙サイズ：A4 ／ 向き：縦
- 余白：なし ／ 倍率：100%
- ヘッダーとフッター：オフ

### 推奨環境

パソコンの Google Chrome または Microsoft Edge でのご利用をおすすめします。スマートフォンでも表示はできますが、入力や印刷はパソコンのほうが快適です。

## 入力した情報の取り扱い

- 入力した内容は、**お使いのパソコンのブラウザの中だけで処理され、外部のサーバーへ送信されることはありません。**
- 「ブラウザに保存」したデータは暗号化されていません。共用のパソコンでお使いの場合は、使い終わったら保存したデータを削除してください。
- Excel出力・Word出力・申出書の見本表示には、インターネット上の部品（ライブラリ）を読み込むため、インターネット接続が必要です。これらの部品の読み込みの際にも、入力内容が送信されることはありません。

## 利用を許可された専門家（資格者代理人）の方へ

※ 士業・同業者の方のご利用には、事前の許可が必要です（「[利用条件](#利用条件)」をご覧ください）。

- 作成者欄で「資格者代理人」を選ぶと、資格・氏名・事務所の住所を入力できます。入力した内容はお使いのブラウザに記憶され、次回から自動で入ります。
- よく使う法務局を登録しておくと、一覧から選ぶだけで提出先を入力できます。
- 必要書類のチェックシートに付く「戸籍の広域交付制度」の解説は、チェックを外すと印刷しないように設定できます。

## このツールで対応していない範囲

次の場合は、このツールでは一覧図を作成できません。専門家（行政書士・司法書士など）または法務局へご相談ください。

- 祖父母や、ひ孫（再代襲相続人）が相続人になる場合
- 数次相続（亡くなった方の死亡後に、相続人が亡くなった場合）
  ※ 必要書類のチェックシートでは、二次相続までの関係図と、手続きに関わる方の人数の目安を表示します。
- 子のパターンで、前の結婚の子や認知した子を描き分ける必要がある場合
- 3枚以上にわたる一覧図、親のパターンでの2枚分け
- 旧民法（家督相続）による一覧図、列挙形式の一覧図
- 相続人がいない場合の手続き
